# PetFactory 桌宠工坊

一键把一张图片变成会动的桌面宠物：AI 分析人物外观/风格/性格 → 生成个性化 15 帧动画 + 像素头像，可选同主题动态壁纸，内置角色人设聊天。

## 功能亮点

- **两阶段帧生成**：先锁定 idle 基准帧，其余 14 帧全部以 idle 为参考，保证帧间一致
- **键鼠互动**：键盘打字波纹、鼠标点击波纹、专注/着急表情、疲劳喘气状态机、气泡对话
- **个性化角色档案**：LLM 为每个人物设计招牌动作、表情、文案、主题配色
- **动态壁纸**：同主题图生视频，一键应用（Lively / Wallpaper Engine）
- **内置聊天**：右键「和我聊天」，按角色人设回复（DeepSeek）

## 目录结构

| 目录 | 说明 |
|------|------|
| `docs/` | 开发文档、用户使用文档 |
| `wallpaper/` | 动态壁纸模块（分辨率检测 / 视频生成 / 应用） |
| `tools/` | 坐标标定工具 |
| `characters/` | 角色数据（`config.json` + `assets/` 15 帧透明图 + `avatar.png`） |
| `config.py` | 共享配置与常量，从 `.env` 读取 API Key |

## 环境要求

- Windows 10/11
- Python 3.12

详见 [`docs/用户使用文档.md`](docs/用户使用文档.md) 与 [`docs/开发文档.md`](docs/开发文档.md)。

## 配置

复制 `.env.example` 为 `.env`，填入你的 API Key：

- `AIGATE_API_KEY`（视觉看图 + 角色档案 + 壁纸视频）
- `ARK_API_KEY`（火山方舟，图片生成）
- `DEEPSEEK_API_KEY`（桌宠聊天）

> ⚠️ `.env` 已加入 `.gitignore`，请勿将真实 Key 提交到仓库。
