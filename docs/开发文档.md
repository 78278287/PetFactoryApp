# PetFactory 桌宠工坊 - 开发文档

## 一、系统架构

### 核心理念：通用播放器 + 每角色输出目录

桌宠播放器只打包一次，运行时读取指定角色目录的 `assets/*.png` 和 `config.json`。不为每个角色重新打包。



```
用户上传图片

&#x20;   │

&#x20;   ▼

┌─────────────────────────────────────────┐

│           AI 生成管线 (pipeline/)         │

│  视觉分析 → 角色档案 → 帧生成 → 后处理    │

└────────────────┬────────────────────────┘

&#x20;                │ 输出 characters/\<name>/

&#x20;                │   ├── config.json

&#x20;                │   ├── assets/ (15帧透明PNG)

&#x20;                │   └── assets\_raw/ (原图)

&#x20;                ▼

┌─────────────────────────────────────────┐

│        通用播放器 (player/pet\_player.py)  │

│  读取 config.json + assets/ 即可运行      │

└─────────────────────────────────────────┘

可选：动态壁纸模块 (wallpaper/)

&#x20; 分辨率检测 → Seedance 图生视频 → Lively/WE 应用
```

### 技术栈



| 组件     | 技术                                                |
| ------ | ------------------------------------------------- |
| GUI    | PyQt5                                             |
| 桌宠渲染   | PyQt5 QWidget（透明无边框）                              |

| 视频生成   | 火山方舟 doubao-seedance-1-0-pro-250528               |
| API 调用 | OpenAI SDK 兼容 + requests                          |

## 三、固定构图模板

为了使键位 / 鼠标坐标成为常量，所有帧使用统一构图模板：

> 角色正面坐在浅木色桌子后面，桌面横贯画面底部约 78% 高度处，桌上有固定精简蓝白键盘 (约 50 键：ESC / 数字行 / 26 字母 / 回车 / 退格 / Shift/Ctrl/Alt/Win/ 长空格 / 方向键)，键盘右侧固定位置有一个白色鼠标，角色居中坐在键盘后方，纯白背景，正方形构图，2048x2048，高质量插画

此模板在 `pipeline/character_profile.py` 的 `COMPOSITION_TEMPLATE` 常量中锁死，DeepSeek 只生成角色外观和每帧动作描述，代码端拼装完整提示词。

## 四、15 帧清单与状态机

### 帧清单



| 帧名            | 用途         |
| ------------- | ---------- |
| idle          | 默认待机       |
| blink         | 眨眼         |
| happy         | 开心表情       |
| sleepy        | 困表情        |
| curious       | 好奇表情       |
| content       | 满足表情       |
| type\_l       | 左手打字       |
| type\_r       | 右手打字       |
| busy\_l       | 左手快速打字（专注） |
| busy\_r       | 右手快速打字（专注） |
| mouse         | 手握鼠标       |
| click         | 点击鼠标       |
| urgent\_click | 快速连点（着急）   |
| tired\_a      | 疲劳呼气（吸气相）  |
| tired\_b      | 疲劳呼气（呼气相）  |

### 状态机逻辑



```
键盘速率 ≥ busy\_rate(5.5键/秒) → 专注 busy\_l / busy\_r

鼠标点击 ≥ urgent\_rate(4次/秒) → 着急 urgent\_click

持续高速 ≥ tired\_after(6秒) → 疲劳 tired\_a/tired\_b 循环(0.42s切换)

停止高速 ≥ tired\_recover(2.6秒) → 恢复正常

休闲状态 → 随机调度 idle\_emotes + blink
```

## 九、分辨率适配说明



* 使用 `QApplication.primaryScreen().geometry()` 获取完整物理分辨率（非 availableGeometry，后者排除任务栏）

* `logicalDotsPerInch()` 获取 DPI，用于判断缩放

* 宽高比匹配最近的标准比例：21:9 (2.333)、16:9 (1.778)、16:10 (1.6)、4:3 (1.333)、1:1 (1.0)、9:16 (0.563)

* 多显示器时取主屏比例

* Seedance 支持的 ratio 参数：16:9、16:10、21:9、1:1、9:16

## 十、常见报错排查



| 报错                      | 原因              | 解决                         |
| ----------------------- | --------------- | -------------------------- |
| `未检测到 ARK_API_KEY`      | 未配置 Ark 密钥      | 设置页填入或编辑 .env              |
| `未检测到 DEEPSEEK_API_KEY` | 未配置 DeepSeek 密钥 | 同上                         |
| `model not found`       | Ark 模型名错误或未开通   | 检查方舟控制台，可能需用 endpoint ID   |
| `insufficient balance`  | 账户余额不足          | 充值                         |
| `rate limit`            | 请求过于频繁          | 等待后重试，帧生成已串行               |
| 桌宠窗口透明但不显示              | 帧 PNG 不存在或路径错   | 检查 assets/ 目录和 config.json |
| 波纹位置偏移                  | 帧构图与默认坐标不匹配     | 使用 calibrate\_gui.py 重新标定  |
| 壁纸应用无反应                 | 未安装 Lively/WE   | 安装后重试，或手动打开 MP4            |

## 十一、设计决策记录



1. **通用播放器而非每角色打包**：减少重复打包，角色即数据（assets + config），播放器只读。

2. **固定构图模板**：锁死键盘 / 鼠标位置，使坐标为常量，避免每角色标定。

3. **DeepSeek 只产出角色 + 动作，不产出完整提示词**：固定模板在代码端拼装，防止模型改写构图导致帧间漂移。

4. **真人图先重绘**：Seedream 以原图为参考重绘为统一风格插画帧，避免程序化拼手。

5. **桌沿检测校验**：从底部向上扫描非透明像素占比 > 85% 的行，自动校验构图对齐。

6. **壁纸可选**：GUI 勾选，不勾选时跳过视频生成，节省 API 调用。

7. **纯 PIL 无 numpy**：降低依赖，素材处理用 floodfill + 逐行扫描。
