# PetFactory 桌宠工坊 - 用户使用文档

## 一、简介

PetFactory 是一个一键生成桌面宠物 + 可选动态壁纸的工具。上传一张动漫或真人人物图片，系统会自动：
1. 分析图片中人物的外貌、风格、配色和性格（AIGate 多模态模型自动分析，否则手动输入描述）
2. 为该人物设计**个性化**动作、表情、气泡文案和主题配色（LLM 驱动，或按人格原型匹配）
3. **两阶段生成** 15 帧桌宠动画：先生成 idle 基准帧并锁定，其余 14 帧全部以 idle 为参考，保证帧间一致性
4. 额外生成该人物的**像素风头像**，用于角色库缩略图
5. 自动去背景、裁剪对齐、桌沿校验、坐标标定
6. 一键启动桌宠，支持**内置聊天**（右键"和我聊天"或双击角色，固定走 DeepSeek）
7. **可选**：生成同主题动态桌面壁纸并一键应用（AIGate 视频接口）

生成的桌宠具备：键盘打字波纹、鼠标点击波纹、快速操作→专注/着急表情、持续高速→疲劳喘气、随机休闲表情、气泡对话、左键拖动、滚轮缩放、右键菜单、角色人设聊天。

## 二、环境要求

- Windows 10/11
- 约 500MB 磁盘空间
- 联网（生成新角色时调用 AI 接口）

## 三、快速开始

### 方式一：双击运行（推荐）

进入 `dist/PetFactoryApp/` 目录，双击 `PetFactoryApp.exe` 即可启动 GUI。桌面也有快捷方式 `PetFactory.lnk`。

### 方式二：开发模式运行

```
cd PetFactory
python main.py
```

### 单独启动桌宠播放器

```
PetFactoryPlayer.exe <角色目录路径>
例如：PetFactoryPlayer.exe characters/miku
```

## 四、API 密钥配置

### 供应商分工

| 功能 | 供应商 | 默认模型 | Key 变量 |
|------|--------|----------|----------|
| 看图分析 + 角色档案 | AIGate | glm-5.3-flash | AIGATE_API_KEY |
| 动态壁纸视频 | AIGate | agnes-video-v2.0 | AIGATE_API_KEY |
| 桌宠聊天 | DeepSeek | deepseek-chat | DEEPSEEK_API_KEY |
| 图片生成（15帧+头像） | 火山方舟 | doubao-seedream-5-0-260128 | ARK_API_KEY |

### 【推荐】AIGate（视觉 + 档案 + 壁纸视频，一个 key）

- 平台地址：https://llm.chudian.site
- 注册获取 Key（格式 `sk-ag-xxxxx`）
- 视觉/档案模型：`glm-5.3-flash`（原生多模态、能看图、1M 上下文）
- 视频模型：`agnes-video-v2.0`（480P/720P/1080P，支持单图生视频/关键帧，1~18秒）
- 在 GUI「设置」页填入 AIGate Key 并保存，或编辑 .env：
  ```
  AIGATE_API_KEY=sk-ag-xxxxxxxx
  AIGATE_BASE_URL=https://llm.chudian.site/v1
  AIGATE_MODEL=glm-5.3-flash
  AIGATE_VIDEO_MODEL=agnes-video-v2.0
  ```
- 该平台**没有静态图片生成能力**，画 15 帧和像素头像仍需方舟 Seedream。

### 【必填】火山引擎方舟 Ark（仅用于图片生成）

- 模型：`doubao-seedream-5-0-260128`（必须 2048x2048，接口要求≥3,686,400 像素）
- 开通地址：https://console.volcengine.com/ark
- 在 GUI「设置」页填入 Ark Key 并保存，或编辑 .env：
  ```
  ARK_API_KEY=your_ark_key
  ARK_IMAGE_MODEL=doubao-seedream-5-0-260128
  ```

### 【桌宠聊天】DeepSeek（固定走 DeepSeek，不走 AIGate）

- 开通地址：https://platform.deepseek.com
- 在 .env 填 `DEEPSEEK_API_KEY=your_key`
- 未配置时聊天窗友好提示"请在设置中填写 DeepSeek API Key"，不影响桌宠其他功能

### 配置方式

- GUI「设置」标签页填入 Key 并保存（自动写入运行目录 .env，打包后同样生效）
- 或直接编辑 exe 同目录的 .env 文件

> 安全提醒：API Key 仅保存在本地 .env 文件中，不会上传。如 Key 曾在对话中暴露，建议到对应控制台轮换。

## 五、使用流程

1. **选择图片**：拖入或点击选择，支持 PNG/JPG/JPEG/WEBP/BMP
2. **设置角色名**：生成的角色目录将使用此名称（非法字符自动清洗）
3. **角色描述（可选）**：AIGate 未配置时手动输入，如「青绿色双马尾蓝眼少女，白衬衫青绿领带」
4. **选择主题色**：初音青绿/科技蓝/暖橙/樱花粉/紫罗兰/墨绿（决定键盘波纹颜色）
5. **【可选】勾选「同时生成同主题动态壁纸」**：桌宠生成完成后自动生成壁纸视频并尝试应用
6. **点击「开始生成」**，等待 3-8 分钟（15 帧逐帧生成+校验+像素头像；勾选壁纸再加 1-3 分钟）
7. 生成完成后点击「启动桌宠」

## 六、动态壁纸

### 生成与应用

- 勾选「同时生成同主题动态壁纸」后，系统以用户上传的人物图为首帧/参考，生成贴合该人物主题、氛围、配色的动态场景
- 提示词强调：画面可无缝循环（loop）、动作轻柔循环、主体稳定、无抖动变形、无文字水印
- 时长默认 6 秒，分辨率默认 1080P
- 生成完成后自动尝试应用壁纸

### 分辨率适配

- 系统自动检测主屏分辨率与比例（本机实测 2560x1600、16:10、144dpi）
- AIGate 视频支持的宽高比：16:9 / 9:16 / 1:1 / 4:3 / 3:4
- **16:10 屏幕**：AIGate 不直接支持 16:10，系统自动选择最接近的 16:9 生成，壁纸引擎（Lively/WE）会自动填充/裁切适配全屏
- 分辨率档位：agnes-video-v2.0 最高 1080P；agnes-video-2.5 / wan3.0-video 可到更高

### 壁纸引擎

系统优先使用以下引擎应用壁纸（自动检测）：

1. **Lively Wallpaper**（推荐，免费开源）
   - 下载：https://github.com/rocksdanister/lively 或 Microsoft Store 搜索
   - 支持命令行一键应用（`--setwp`）
   - 安装后系统自动调用，无需手动操作

2. **Wallpaper Engine**（Steam 付费，appid 431960）
   - 已安装时自动启动并引导导入
   - 无稳定命令行接口，需在 WE 中手动「打开本地文件」选择视频

3. **都未安装**：弹窗提示安装指引，一键打开官方下载页；视频文件已保存到 `output/` 目录，可手动导入

## 七、两阶段生成原理（保证帧一致性）

- **阶段1**：用用户上传的原图生成 idle 基准帧，校验桌沿位置合格后锁定
- **阶段2**：其余 14 帧全部以 idle 为参考图，提示词强锁死（除手部动作和脸部表情外，发型/身体/服装/桌子/键盘/鼠标/配色/视角完全一致）
- 每帧自动检测桌沿，与 idle 偏差 >25px 自动重生成（最多3次）
- 最终所有帧统一裁剪对齐，播放时不会"像换图"

## 八、个性化角色档案

系统会为每个人物设计专属的：
- **招牌动作**：元气偶像会蹦跳比耶、高冷剑客会精准沉稳、软萌萝莉会害羞乖巧
- **表情集合**：开心/疲劳/着急等表情贴合人物性格
- **气泡文案**：20 条互动文案 + 6 条疲劳文案，说话语气因人而异
- **主题配色**：键盘/鼠标颜色和波纹色适配人物主色调

AIGate 可用时由 LLM 设计；不可用时按关键词自动匹配人格原型（元气偶像/高冷剑客/软萌萝莉/通用）。

## 九、桌宠操作说明

| 操作 | 效果 |
|------|------|
| 左键拖动 | 移动桌宠位置 |
| 滚轮 | 缩放大小（0.1x ~ 0.6x） |
| 左键单击 | 触发互动动画 + 气泡对话 |
| 右键 | 弹出菜单（大小/置顶/和我聊天/退出） |
| 双击角色 | 打开聊天窗 |
| 敲键盘 | 桌宠双手交替打字，按键位置亮波纹 |
| 快速打字（≥5.5键/秒） | 切换为专注表情 |
| 点鼠标 | 桌宠手握鼠标，按键亮红色波纹 |
| 快速连点（≥4次/秒） | 切换为着急表情 |
| 持续高速操作 6 秒 | 进入疲劳喘气状态 |
| 停止操作 2.6 秒 | 从疲劳恢复 |

## 十、内置聊天功能

- 右键菜单选择「和我聊天」，或**双击桌宠**，弹出半透明聊天小窗
- 桌宠会以该角色的人设（性格、身份、说话语气）回复
- **聊天固定走 DeepSeek**（deepseek-chat），需要在设置中填写 DEEPSEEK_API_KEY
- 短回复（<20字）会同时显示在桌宠头顶气泡
- 聊天在独立线程运行，不影响键鼠监听和状态机
- 未配置 DeepSeek Key 时聊天窗友好提示，不崩溃

## 十一、角色管理

- 所有角色保存在 `characters/` 目录，目录名即角色名
- GUI 右侧「角色库」显示像素头像 + 角色名，选中后点「启动选中」
- 每个角色包含：`config.json`（配置）、`assets/`（15帧透明图）、`assets_raw/`（原始生成图，可删）、`avatar.png`（像素头像）
- 内置角色：`sample`（BongoCat）、`miku`（初音未来）

## 十二、坐标标定（高级）

如果波纹位置不对齐：
```
python tools/calibrate_gui.py characters/<角色名>
```
鼠标点击实际键位，按 S 保存。系统也会在生成时根据桌沿位置自动调整坐标。

## 十三、常见问题

**Q: 提示未检测到 ARK_API_KEY？**
A: 在设置中填入 Ark Key 并保存。图片生成必须用方舟。

**Q: 视觉分析失败 / 提示视觉模型不可用？**
A: 推荐配置 AIGate Key（glm-5.3-flash 原生支持看图）。未配置时在「角色描述」中手动填写外貌即可，不影响生成。

**Q: 角色档案用的是默认文案？**
A: 未配置 AIGate key 时，系统按关键词匹配人格原型。配置 AIGate key 后可获得 LLM 个性化设计。

**Q: 聊天窗提示请填写 Key？**
A: 聊天固定走 DeepSeek，请在设置中填入 DEEPSEEK_API_KEY。

**Q: 壁纸生成失败？**
A: 壁纸需要 AIGATE_API_KEY。确认 key 有效且视频模型已开通（默认 agnes-video-v2.0）。视频文件保存在 output/ 目录。

**Q: 壁纸没有自动应用？**
A: 需要安装 Lively Wallpaper（免费，推荐）或 Wallpaper Engine（Steam付费）。未安装时系统会提示下载指引，视频文件可手动导入。

**Q: 16:10 屏幕壁纸有黑边？**
A: AIGate 视频不直接支持 16:10，系统用 16:9 生成。在 Lively 中设置"填充"模式可全屏无黑边。

**Q: 帧位置不一致 / 播放像换图？**
A: 新版已采用两阶段生成（idle锁定+其余帧以idle为参考），如仍有问题可重新生成。

**Q: 桌宠窗口不显示？**
A: 检查右下角，右键菜单可调大小。

**Q: 如何修改气泡文案？**
A: 编辑角色目录 config.json 的 dialogues 数组。

**Q: 打包后 .env 不生效？**
A: 打包版从 exe 同目录读取 .env。GUI 设置页保存的 key 会写入该目录的 .env。
